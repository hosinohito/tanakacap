改変済みのVRChat向け3Dアバターを、Webカメラ1台でリアルタイムに動かすためのプロジェクト。名称はフォルダ名に基づく仮称。

Unityの変換プラグインでユーザー自身の改変済みアバターを書き出し、専用のUnityアプリで読み込む。着席での頭、まばたき、口、上半身、大まかな腕・手の動きを優先し、元のシェーダーの見た目と自然な髪・服の揺れを活かす。

RTX 4090上で、リアルタイムに実用できる範囲の最高精度を目指す。GPU推論は必須。負荷低減は、基準となる品質を作った後に追加する。

## 成果物の構想

- **変換プラグイン**：Unity上の改変済みVRCアバターを、専用アプリ向けに非破壊で変換・書き出す。
- **再生・キャプチャアプリ**：書き出したファイルを読み込み、カメラ映像から推定した動きをアバターに反映する。

購入した配布パッケージをアプリ単体で直接解釈する方式、VRMへの一律変換、iPhone必須の構成は、現在の主案ではない。
