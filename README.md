# TanakaCap

**いつものVRCアバターを、Webカメラ1台で動かして、そのままOBSへ。**

TanakaCapは、改変済みのVRCアバターの見た目を活かして使う、Webカメラ向けのモーションキャプチャーソフトです。シェーダーの表現、PhysBoneによる髪や服の揺れ、パーティクルをできるだけ保ったまま、配信へ持ち出すことを目指しています。

頭や視線、眉・まぶた・口の動きに加え、腕・手・指の動きをカメラから捉えます。パーフェクトシンクのような豊かな表情と、身振りが伝わるアバター表現を目指します。Perfect Sync／ARKit系の表情キーも活用しますが、Perfect Sync自体を再実装するものではありません。

映像はSpout2でOBSへ透過出力できます。GPU上の画像を共有するため、クロマキー処理や転送時の動画圧縮を挟まず、背景の透明度を保った映像として扱えます。

PhysBoneは元の設定を使った独自の近似再現です。シェーダーやパーティクルにも対応範囲があり、VRChatと完全に同じ動作を保証するものではありません。

## ダウンロード・使い方

[最新版をダウンロード](https://github.com/hosinohito/tanakacap/releases/latest)し、[使い方](docs/user_guide.txt)に沿って導入してください。ZIPが複数ある場合はすべてダウンロードし、同じフォルダーへ展開します。

実行に必要なPython・ライブラリ・推論モデルは配布物に含まれます。アバターは付属しません。お持ちのVRCアバターを、付属のUnityプラグインで書き出して使います。着せ替えツールごとの準備も使い方に記載しています。

## 使用環境

- Windows 64bit、NVIDIA RTX GPU、Webカメラ。
- アバターの書き出しには、Unity 2022.3.22f1のVRCSDKプロジェクトが必要です。書き出し済みアバターの再生にはUnity Editorは不要です。
- OBSで透過映像を使う場合は、OBS StudioとSpout2プラグインを導入します。

着席・カメラ1台でのリアルタイム配信を主な用途としています。通常の画面には実写カメラ映像を表示しません。

## 対応範囲

頭・表情・腕・手・指を追跡し、用途に合わせて推論モードを選べます。表情は既存のPerfect Sync／ARKit系、MMD、VRCのキーを機能ごとに優先して使用します。自動で独自キーを補うモードも用意しています。

VRChatのメニュー、Animatorによるギミック、スクリプトの動作をすべて再現するものではありません。書き出し時や再生時に省略した機能は、レポートやログで確認できます。
