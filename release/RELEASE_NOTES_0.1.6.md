# TanakaCap 0.1.6

- lilToonなどを使用したアクセサリーの色が、本来の色より白くなったり暗くなったりする問題を修正しました。
- アバターに設定された標準の手・指コライダーで、髪や衣服などの揺れ物に触れられるようになりました。手・指のサイズや無効設定、揺れ物側の自己衝突の許可設定を引き継ぎます。
- 腕を真横に広げたとき、斜め前へ出てしまう動きを改善しました。
- 腕を伸ばしたときの肘のねじれと、奥行きの切り替わりによる急な回転を軽減しました。
- 「実験」タブに「映像内の位置に追従」を追加しました。左右・上下の移動を反映できます。初期値はOFFで、顔に合わせた接近と併用できます。
- 髪やアクセサリーの揺れが急激に反転する問題を修正しました。
- アバター書き出し時に、無効にした揺れ物用コライダーを取り込まないようにしました。反映には新しいプラグインでの再書き出しが必要です。

手で揺れ物に触れる機能を使う場合は、同梱の新しいUnityプラグインを導入し、アバターを再度書き出してください。以前のアバターファイルも読み込めますが、手との接触機能は追加されません。

揺れ方はVRChatと完全に同じではありません。つかむ操作や固定する操作には対応していません。
