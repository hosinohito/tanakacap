TanakaCapの初期公開版です。Webカメラで3Dアバターを動かし、OBSへ透過出力できます。

## ダウンロードと起動

1. `TanakaCap-0.1.0-part01.zip` と `TanakaCap-0.1.0-part02.zip` の**両方**をダウンロードし、同じ場所へ展開してください。
2. `TanakaCap/使い方.md` に従い、付属のUnityプラグインでご自身のアバターを書き出します。
3. `TanakaCap/TanakaCap.bat` から起動します。

Windows 64bit・NVIDIA RTXが必要です。書き出しにはUnity 2022.3.22f1が必要ですが、アプリの実行だけならUnity Editor・Pythonの個別導入は不要です。アバターは同梱していません。

MA・VRCFury・キセテネ・AvatarTools別の書き出し準備と、AAO併用時の手順を説明書に記載しました。原本を残すため、プロジェクトを複製して作業してください。

## 含まれるもの

変換プラグイン、本体と操作UI、実行ライブラリ、推論モデル、利用説明書、ライセンス、FFmpegの対応ソース・ビルド手順。

独自コードはMITです。第三者ライブラリ・モデルにはそれぞれのライセンスが適用されます。

## 現在の確認範囲

主な検証環境はRTX 4090・HAOLANです。他アバターや着せ替えツールのすべての組み合わせ、新規PCでの導入は確認できていません。VRChatの衣装切り替えメニューや全ギミックの互換性はありません。Discord向け仮想カメラと音声口パクは未対応です。

ZIPのCRC、同梱Pythonの起動、ライセンス通知・モデル・ランタイムのSHA照合を実施しています。`SHA256SUMS.txt` でダウンロードしたZIPを照合できます。
