# 頭姿勢だけの最軽量構成（試験）

2026-09-12。ユーザー指定の目標は頭姿勢専用モデル＋音声口パク。顔の表情/ランドマーク、目線、体のモデルを省略する。音声口パクは将来課題で、今回実装しない。

今回の実装はMobileNet V3 smallによる頭向きのみ。通常構成は維持。run-avatar-lab.ps1 -HeadOnly -NoLog、またはデスクトップtanakacap-head-only.bat。初回に頭を少し余白付きで囲みEnter。Pで停止/再開、Rで範囲を再選択。-HeadRoi 618,246,170,165のような明示範囲も指定可能（各人/カメラで異なる）。

固定範囲であり、範囲内に頭が存在する確率を出すモデルではない。空画像や別物を頭と解釈する可能性があり、自動ロスト/復帰は未達。無効な回転行列・極端な角度では頭を保持するが、人物不在検出の代用とは扱わない。顔領域を見つける検出/追跡と、表情ランドマーク推論の要否は別。今後、頭領域の軽い追跡・再検出を比較する。

送信のheadTrackedをfaceTrackedから分離。頭の姿勢に従来の3平均/重複2観測を適用。表情・口・体・腕・掌・指は更新しない。頭停止時は最後の姿勢、目線は既存のカメラ方向復帰。頭専用で顔サイズからの接近は使わない。

## 追加モデルの取得

作者の一次資料：https://github.com/yakhyo/head-pose-estimation
重み：https://github.com/yakhyo/head-pose-estimation/releases/download/weights/mobilenetv3_small.onnx

モデルを上記URLから models/head-mobilenetv3-small.onnx に保存する。SHA256：e8ae4d932b3d13221638fc72e171603e020c6da28b770753f76146867f40e190。実行時にも照合。CUDA必須、CPUへの暗黙フォールバックなし。RGB/ImageNet正規化、出力3x3回転行列から頭角度へ変換。PyTorchの追加導入なし。

作者はコードをMITで公開（[ライセンス原文](HEAD_MODEL_LICENSE.txt)）。作者READMEでは300W-LPによる学習。コードのMIT表記だけで全学習資産・重みの一般配布条件を監査済みとは扱わず、今回の重みはローカル開発評価のみ、Player/Exporter/Gitに同梱しない。正式採用・配布時は重みとデータ由来条件を確認する。モデル選定理由は小型の直接姿勢出力を既存ONNX CUDA環境で測れること。最高精度モデルとして選んだものではない。

## 検証

既存録画でCUDA node実行を確認。ORT詳細トレースOFFでは300観測、モデル処理中央値約1.6ms、入力decodeを含むループ約3.2ms（Player/OBS非併用、精度/表示遅延の保証ではない）。画像±20度回転でロール方向を検査し、当初の不要な符号反転を撤去。頭のみの実PlayerテストでheadPitch22度の反映を確認。既存モデルとの実人物品質比較・頭の自動再取得・音声口パクは未達。
