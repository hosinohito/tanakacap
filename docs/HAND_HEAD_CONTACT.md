# 掌・指の頭回避と肘ねじれの調査

2026-09-21。通常アバターのauto-customで、ユーザー撮影 `20260921T044937-004325Z` の同一推論を再生。実写表示・実カメラ試験なし。

## 手全体の接触回避

頭・手首だけの判定に加え、掌、各指節、指先を表示アバターのボーン位置から取得する。指節と手首〜指根、指根間を約8mm間隔で補間する。末端の子ボーンがあれば指先として使い、なければ直前の指節長の0.7倍で推定する。指ボーンが不足するアバターは取得できる点だけで判定する。

頭の楕円体に、前腕長から求める2〜8mmの厚みを加えた判定範囲を用いる。内部の点から最寄り表面への変位を求め、全点へ同じ変位を加えて再判定する。最大16反復の局所解で、全候補を探索した数学的な最小移動や正確なメッシュ衝突ではない。

変位を腕のIKへ渡し、手の世界回転、指のローカル位置・回転、腕の骨長を保つ。上腕・前腕を回して手全体を逃がし、指を独立に伸ばしたり位置だけ書き換えたりしない。腕の到達範囲を適用した後に最大3回再判定する。最終表示姿勢（掌・指と欠測補間を反映した後）に適用する。通常の前方・体横断補正はONのまま、接触回避が最後に作用するため、矛盾する制約の同時達成は保証しない。

指の厚み・指先推定・頭代理形状・点間隔による近似があり、メッシュ全体の完全な非貫通は保証しない。到達不能なら腕を伸ばさず残差を診断へ記録する。指を曲げて接触させる処理や接触から推論の握り形状を変更する処理は含まない。

通常ON。オフライン比較専用 `--diagnostic-wrist-head-only` で直前の手首だけの方式を再現する。通常起動ではこの引数を拒否する。

## 肘の調査

`AvatarVideo` はオフライン時に上腕・前腕のローカル回転、表示ねじり量、要求ねじり量、原本の関節回転を基準とした肘の軸回り成分を保存する。`tools/diagnostics/audit_elbow_twist.py` で集計する。肘の軸回り成分は回転分解の診断値で、人体の関節角やメッシュの破綻量ではない。

手首のみの従来方式でも左右とも前腕ねじりの既存上限±160度へ達する。絶対値120度超は左247/901、右425/901フレーム。肘のローカル回転変化は左最大143.44度/描画フレーム（21.967秒）、右最大40.92度。新接触を有効にしてもこの最大値は同じで、新接触が主因ではない。

コード上、掌の向きに合わせるねじりは±160度と広く、上腕と前腕の基準回転は原本の方向からそれぞれ独立に生成している。このため表示用 `twist` の制限が、親の上腕に対する肘の最終ねじれの制限にはならない。

最大急回転の直前21.938秒に左CrossBodyが0→0.582となる。体横断の前方条件を満たすために補間を飛ばして解へ移す処理があり、候補原因。21.968秒には入力肘のZ符号も反転しており、別の不安定要素がある。体横断だけをOFFにした診断では、同じ21.967秒の左肘相対回転が143.44→13.89度になった。一方で全編最大は85.15度、右最大46.50度で、±160度の張付きも残る。体横断はこの急回転の寄与因子だが、単にOFFにしても全体解決ではない。通常設定はONを維持する。

修正候補は、肘を上腕に対する曲げ平面と軸ねじりに分けて最終相対角を制限すること、体横断の制約を補間後も連続的に解くこと、投影復元の肘Z分岐の切替を安定させること。今回、回転制限値や肘推定は変更していない。
