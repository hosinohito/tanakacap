# 接近時の横飛び・肘の追従調査（2026-09-12）

対象：`results/20260911T214959-421912Z-rtmw-l-384/frames.jsonl`、1284frame。距離比0.8未満かつ距離有効が536frame。そのうち右腕無効323、左腕無効0、短時間ArmHeldは左右各1。実人物の見た現象のすべてを右腕欠測だけで説明しない。

## 修正した経路

1. 旧 `Quaternion.Euler(pitch,yaw,roll)` は前傾方向までyawで横へ向けていた。着席時のみ `Rx(pitch) * Euler(0,yaw,roll)` へ変更し、前傾軸をrootのカメラ対応X軸に固定。SpineとChestの両方を同じ順序で構成。旧translate/OFFの胴体回転式は維持。
2. `lowerUntwisted` はワールド回転のキャッシュで、親の上腕が胴体追従しても更新されなかった。胴体更新前後の親回転差でキャッシュを移送し、古い向きからの前腕補間を避ける。観測された腕の目標方向は変更しない。
3. Pythonが送る短時間の `left/rightArmHeld` をUnityが読み取っていなかった。今回読み取り、保持packetで過去のカメラ基準の腕/掌方向を再適用しない。ローカル関節姿勢を維持して胸へ追従する。通常の腕無効も従来のローカル姿勢保持、前腕キャッシュも親に追従。今回のheldは各1frameだけなので主因と誇張しない。

見えている腕を前傾分だけ一律回転する補正は追加していない。観測はカメラ基準であり、机に置いた肘などもあり得るため。欠測中の本当の肘の位置を復元したわけではない。
