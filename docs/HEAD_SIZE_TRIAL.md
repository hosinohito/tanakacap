# 頭角度の2D比率試行（2026-09-13）

後続のユーザー指定で既定をpnpへ戻した。以下は試行時の記録で、size2dは任意選択として残す。

ユーザーは頭のガタつきを申告し、見かけの大きさからの推定を試すよう指定した。`size2d`を試行既定へ変更。UIの「入力・推論」→「頭角度」で`pnp`へ戻せる。適用は再起動。頭のみモードは別の直接回転推定モデルなので対象外。

直前の通常`pnp`は、ピッチだけXY観測を固定3D顔テンプレートへ当てはめ、ヨー/ロールはXYの位置関係。モデルが出したZは通常の頭角度へ使っていなかった。固定テンプレートの奥行きとモデル推定Zは区別する。

`size2d`の頭角度はXYのみ。左右それぞれの眼端2点の中心で横軸と眼間距離を作り、鼻4点の中心までの縦横距離を眼間距離で割る。正面相当で比率変動0.04未満の10観測を初期基準とし、縦比率差からピッチ、横比率差からヨー、眼軸の傾きからロールを駆動。開口/顎/まばたきの点を角度計算へ使わない。ピッチの100×既存gain、ヨー100は表示感度で、実角度の復元ではない。欠測では最後の角度を保持する。時間処理は従来の3平均/stride1（計4フレームで方向確認）のまま。

純粋な幅/高さの縮みだけでは回転方向と距離を一意に決められないため、鼻の相対位置も使う。画像の一様な拡大縮小・移動には不変だが、実際の接近による透視変化、横向きとピッチの混同、顔形状の個人差、大きいピッチでの非線形性は残る。初期基準が実際に正面かは画像の正解を持たず保証できない。静止時品質が改善したとは扱わない。

口・眉の既存PnP正面化は独立して維持する。そのためPnP処理自体の削減ではない。PnPが失敗しても有効な比率から頭を更新し、口・眉の失敗フラグは従来のまま。腕・肩・掌・指・距離・揺れ物を変更しない。
