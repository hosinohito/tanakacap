# 表情の既存キー対応と実験用自動生成

2026-09-13ユーザー指定：パーフェクトシンクは既存キーの対応先として使うだけで、表情推論そのものを再実装しない。機能ごとにARKit/パーフェクトシンク→MMD→VRCの既存キーを優先する。足りない機能を無理に捏造しない。通常版では目線を含め独自キーを排除する。

別途、従来実験を引き継ぐ自動独自キーモードをオプションで追加する。口角左右分割・唇限定横移動・瞳限定移動、ガンマ・開口時上げ抑制・強調度0・中立校正を踏襲。モデルを問わず自然になる保証はない。原本を変更せず、材料や安全な対象が見つからなければ生成を省略する。

## 眉の追加と保存デモ

追加モデルなし。RTMW3Dの既存68顔点の眉17〜26と眼端を用いる。まぶたの開閉ではなく眼端を基準に、距離/ロールを除いた眉の内外高さを求める。通常PnPで頭向きを除く際は固定の眉深度平面を使い、推定Zは使わない。最初の安定10観測を中立とし、その後固定。3平均/stride1の方向確認を通し、欠測ではアバターの最後の眉を保持する。左右別の内側/外側4制御。任意人物の中立表情を自動判定した保証ではない。

HAOLANでは既存MMD眉の上/下/困る/怒りを使用する。左右独立キーがないため両側平均で近似する。実Playerで頂点変形を検査（results/brows/demo-smoke.logのTANAKACAP_BROWS_VERIFIED）、既存の口/目/腕回帰も成功。237 Python tests。既存FP16全録画で5,071/5,187眉有効。眉の目視比較動画はユーザー指定で作らない。

眉追加後・汎用化前のPlayer一式をbuilds/demos/haolan-custom-browsへ保存。旧HAOLAN固有の口/目線キーを含み、自作モーションの眉も動く。今後の通常ビルドで上書きしない。素材許諾・自作モーション0BSDは別扱い。一般公開の指示はない。

汎用化と自動生成はこのチェックポイントの後に実装する。比較入力はresults/comparisons/expression-mapping/replay.jsonl。以前のFP16全編制御を維持して眉だけ一度追加し、全方式に全く同じpacket/時計を渡す。推論・眉そのものの比較ではなく、アバターへの対応方式の比較とする。
