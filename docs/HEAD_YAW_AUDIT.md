# 顔ヨーの円周モデルと頭の追従

2026-09-23のユーザー指定を反映。通常full/face_headのPnP経路が対象。以前の鼻横ずれ比率×−100から円周上の両目の弦の投影長による角度復元へ変更。ピッチ・ヨー・ロール共通の可変速度追従をUI既定・このPCの保存設定・run-avatar.ps1で有効化。UIの固定速度選択は実験用に残す。既存Playerの--adaptive-head-followを使用するため再ビルド不要。

## ヨーの計算

両目を円周上の固定された2点、その間を弦とみなし、正面時の弦長W0に対して横向きθの投影長をW=W0*cos(θ)と近似する。角度の大きさはdegrees(acos(clip(W/W0,0,1)))、向きは鼻先が両眼中心のどちら側にあるかで決め、出力は±60度に制限する。鼻のずれの大きさを角度倍率には使わない。円の半径そのものは比で消える。弱透視・両眼が同じ奥行きにある固定点という近似で、実人物の正解角度を保証しない。

- 各眼の目頭・目尻の中点を使用。瞼を含む6点平均は用いず、閉眼による基準点変動を抑える。
- 鼻の横ずれは両目を結ぶ軸へ投影し、ロールに対応。
- 接近時の見かけの拡大を分離するため、目の間隔pxにPnPから求めた眼中心面のカメラ距離/focalを掛ける。既存の汎用顔テンプレートの眼中心をPnP回転・移動でカメラ座標へ変換する。学習モデルのZや新規推論は不要。PnPのヨー角を直接出力する方式ではないが、距離補正はPnPの姿勢推定に依存する。
- 鼻横ずれが眼間隔の8%未満の正面付近で、10観測の補正後弦長が3%以内に収まったら中央値をW0とする。取得前はヨー0。顔を横に向けたまま起動すると校正待ちになる。
- 校正後のW0は固定。PnP不成立や必要点の不足時は最後のヨーを保持。基準の取得には個人差や推定誤差が残る。
- arccosは正面近くで長さの微小誤差に敏感。追加のガンマや恣意的な感度曲線は入れず、既存の4フレーム法と可変速度追従を使用する。

## 後段の処理

FaceFilterは3観測平均・stride1、その値の0.25度以下の差は保持し、同方向変化を確認して採用。Unityはヨー±60度、ピッチ±40度、ロール±35度へ制限。頭全体の目標との差0〜12度をSmoothstepで変換し、追従率6〜45/s、係数1−exp(−rate*dt)のQuaternion.Slerpを適用する。3軸は同じ回転補間を受け、軸ごとに別々の速度を計算する方式ではない。胴体回転を二重加算しない。

実験size2dは独自ヨーで上書きする。depth3d/pnp_depthmouth/legacyと頭のみ別モデルは従来のそれぞれの経路を保つ。新円周ヨーの通常確認はPnPを選択する。ピッチ推定の1.8倍ゲインは変更なし。
