# 現在の推論経路

最新採用（2026-09-13）：ピッチはPnP・口角はZ。通常body3d/pnp_depthmouth、`-HeadPoseMode pnp`で両方旧補正へ。test/liveは採用構成。以下のdepth3d試行・通常separate/pnpは過去の状態。[最新引き継ぎ](../HANDOFF.md)。

追加試行：body3d顔＋head_pose_mode=depth3dでは、PnP/仮定唇深度を使わず、既存推論の顔Zから回転を求めて口輪郭を正面へ戻す。[可逆操作・計測](FACE_DEPTH_TRIAL.md)。通常pnpを維持。

追加試行：`face_source=body3d`では下記RTMW-Lを省略し、RTMW3D-Xの同じ1回のXY出力を顔にも使う。虹彩モデル・補正は維持。通常はseparate。[切替・比較](FACE_SOURCE_TRIAL.md)。

2026-09-13。通常は全部ON、B+C（graph/人物検出3間隔/YOLOX-M）。入力→人物ROI→RTMW-L→RTMW3D→頭/虹彩/表情/距離/体補正→UDP→Unityの順に処理する。部位ごとに別スレッドで並列推論しているわけではない。人物検出を省く観測でも、詳細モデルは実行する。

| 部位・段階 | モデル／処理場所 | していること | 分かったこと・限界 |
|---|---|---|---|
| 映像取得 | カメラ・CPU画像取得 | 最新画像を取り出し、古い入力を溜めない | カメラfps・認識Hz・描画fpsは別。GPU使用率だけでは待ち時間を説明できない |
| 人物範囲 | YOLOX-M/CUDA＋CPU画像追跡 | 3実検出で確定後、最大2観測の疎な画像追跡でROI更新。不良/期限切れは即再検出 | 大きな負荷源。tinyへの置換は切り出しを変え、詳細モデルの奥行きも変えた |
| 顔・参照点 | RTMW-L/CUDA | 全身133点の2D推定を顔・参照点として利用。顔専用モデルではない | 点の取得と、向き/表情の分離は別問題 |
| 頭姿勢 | 顔2D点・PnP等/CPU | 基準形状との幾何からピッチ等を補正。基準姿勢・感度調整 | 向きが取れないと口角などへ誤りが波及。専用頭モデルを使うのはhead_onlyだけ |
| まばたき・口 | 顔2D点＋独自形状計算/CPU→Unityモーフ | 開閉・幅・口角・左右非対称・横寄せ。向き補正、開口時口角抑制、ガンマカーブ | 映像の再現とアバター表現は同じではない。横寄せは唇周辺限定で顎/首を保護 |
| 目線 | 顔点→眼crop→虹彩モデル/CUDA→CPU | 左右眼の輪郭に対する虹彩位置を求め、瞳限定モーフへ | 眼骨の重みが小さく入力があっても見えなかった。ロストは例外的にカメラ方向へ緩やかに復帰 |
| 接近・距離 | 顔の尺度/CPU→Unity | 顔サイズ変化を安定化し、移動＋軽い前傾へ反映 | 生尺度は震える。頭の高さと腕の連動も必要。実距離センサーではない |
| 体・腕・手の点 | RTMW3D-X/CUDA | 同じ人物ROIから133点XYと相対Zを取得 | 奥行きは提供されるが不確か。着席、袖、遮蔽、投影短縮で別の姿勢を選び得る。胴体だけ独立OFF不可 |
| 肩・胴体 | 体点＋顔尺度＋独自幾何/CPU | ロール等、顔尺度補正した肩幅からヨー量、肘前後から方向。前傾の肩幅縮みも補正 | 幅やZの単独利用で正面ヨーが生じる。実用品質は残件 |
| 腕・肘 | 体点＋常時骨長校正＋front_projection/CPU→Unity関節 | 顔尺度で距離を補正した骨長と投影短縮から前後を復元。交差・埋まり・肘の方向も処理 | 長さを合わせるだけでは逆肘が生じる。推定、補正、アバター関節を分けて監査する |
| 掌・手首・指 | 体モデルの3D手点＋部位別計算/CPU→Unity | 掌方向・前腕ひねり・指屈曲。回転経路・可動域・欠測を処理 | 回転の枝選びで遠回り。指点の乱れが誤屈曲へ直結、左指等の残件あり |
| 時間処理 | 部位別フィルター/CPU | 基本は3フレーム平均を重複させた2点で方向継続を確認、各部位固有処理も併用 | 平滑化は遅れとの交換条件。目線以外は追跡停止時に最後の姿勢を保持 |
| 表示・出力 | UDP→Unity/GPU描画 | 骨・モーフ・距離、独自揺れ物、lilToon、軽量AA、Spout透過 | 軸・モーフ対象範囲でも不具合が起こる。推定点の表示だけでは合格にしない |

head_onlyはYuNet頭領域→MobileNet系直接頭姿勢→Unity。顔表情・体・虹彩は省略する。音声口パクは後日。face_headはRTMW-Lを残す別の軽量構成。

BはGPUメモリ・呼出し方、C/Dは人物ROIを変更。今回、詳細モデル・FP32・部位別補正・揺れ物は変更しない。速度・品質差・戻し方は[FULL_MODE_OPTIMIZATION.md](FULL_MODE_OPTIMIZATION.md)。
