# 部位別の大げさ度（2026-09-13）

UIの「表情」に眉・目（目線）・まぶた（閉じ）・口の独立スライダーを追加。各0〜1の連続値。0は現在の通常設定に対する追加作用なし、1は最大。既存の眉gain2や目線基準感度4は別の基準として維持する。既存キー優先/auto-custom双方で表示側に適用する。入力推定、4フレーム法、頭角度PnPは変更しない。適用は従来どおり保存・再起動。

| UI | 追加強調0→1 | Player引数 |
|---|---|---|
| 眉 | 表示値1→1.75倍、±1上限 | --brow-exaggeration |
| 目（目線） | 既存gaze_gainに1→1.5倍、水平±20/垂直±12度の上限維持 | --eye-exaggeration |
| まぶた | 閉眼量1→1.8倍、0〜1上限 | --eyelid-exaggeration |
| 口 | 開口/幅/丸め/左右口角/横寄せ/弓形の値1→1.7倍、各範囲上限。口角の既存強調との大きい方も使用 | --mouth-exaggeration |

追加強調0は無表情へのOFFではない。眉の左右内外、目線のロスト時カメラ方向復帰、まぶたの左右、口の非対称と閉口時横寄せは維持。眉の可変追従後に強調、目閉じの検出器/固定EAR閾値/時間処理は変更しない。まぶたスライダーは閉眼の表示感度であり、見逃したまばたきを復元する機能ではない。キーがない既存アバターで機能を生成することもない。

保存デモ用tcapを使う経路（--use-demo-shape-keys）は4項目を常に1へ固定。UIで同アバターを選んだ場合も値1を表示してスライダーを無効化し、実動作と食い違わせない。通常アバターなら4項目を独立操作できる。demo/testのbatとデモ用motion batも最新Playerを使う。凍結した旧Player/素材は履歴用に保存し、ハッシュは維持。

不足していた口寄せキーを、旧来の唇限定マスク（4mm/上下14mm帯）から実行時コピーへ補完。既存TCキーは再生成・置換しない。口・目線の不足キーだけを補い、眉は左右分割を維持する。通常existingモードで独自生成しない規則は維持。以前の「デモのshiftL未マップ」は今回の補完で解消。

比較動画は`results/avatar-videos/facial-exaggeration/face-closeup.mp4`（左normal/右exaggerated）。同じ新30秒録画853packet/PnP/眉gain2/可変眉/左右分割/補完済みデモを使用。左は4項目0、右は4項目1。同じ最新版の比較で、旧Playerの再現ではない。比較専用の--comparison-neutral-exaggerationは--render-replay時だけ許可し、通常デモ起動では拒否。出力は30fpsオフラインで、推論遅延の比較ではない。
