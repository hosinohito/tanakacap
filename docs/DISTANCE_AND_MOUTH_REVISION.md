# 顔による距離補正・回転整理・指と口の変更

2026-09-12。ユーザー指定の実装と工学的近似を区別する。実人物の品質は未合格。

## 採用した変更

- 胴体の前後（pitch）上限を±30→±50度、ひねり（yaw）を±55→±80度へ変更。PythonとUnity両方に反映。roll±25度と平均方式、描画補間、背骨/胸の分配は維持。「前後とひねり」は直前の肩の会話に基づき胴体と解釈した。腕の前方条件や手首の数値上限を広げる指示とは扱っていない。
- 顔の相対的な大きさでXYの距離尺度を更新し、その尺度で腕長を常時校正する。5秒に10観測で支持された最大値、起動中に短縮しない条件は維持する。
- 前腕の中立方向を肘面と過去の半球選択から作るForearmNeutralを撤去。アバターの元姿勢から前腕方向へ最短回転した基準を使用する。過去の候補符号によって回転制限の中心が変わる経路を除く。
- 手首目標の回旋が±140度（前腕100＋残余40）の範囲なら実現可能な枝を選ぶ。前腕が反対側の制約端へ張り付き続ける問題を修正。範囲外の180度付近は従来の連続側を維持し、単発の境界通過で反転しない。前腕±100、手首曲げ60、残余ねじり±40、速度制限は維持。人体の普遍的限界ではなく暫定制御値。
- 指の骨長が履歴に比べて大きく崩れた観測を除外する。手全体の平行移動/回転を禁止しない。対象の指だけ最後の姿勢で保持し、正常観測で再開する。
- 口の開閉感度2→3.5倍、横幅2.5→3.5倍。開閉/幅の出力上限は同じ。すぼめ（mouthRound）と口角上がり（mouthSmile）を追加し、既存の3平均stride1の確認へ通す。

## 顔尺度の実装と限界

`tanakacap/face_scale.py`は既存133点の顔27/28/29/30（鼻梁〜鼻先）、36/39/42/45（目の角）の8点を使う。顎・唇・まぶたの開閉点を使わないため、顎が下がることを直接距離変化として数えない。固定した最初の有効な点群へアフィン変換を当てはめ、その最大特異値を相対拡大率とする。片方の方向が顔の回転で縮む場合、縮んでいない方向を使える弱透視の近似である。縦/横の単純な条件分岐ではない。

最初の尺度だけ従来の名目肩幅0.36mで固定する。以後は基準尺度/拡大率を用い、肩の回転へ戻して尺度を上書きしない。信頼度0.5、点群の広がり、アフィン残差0.12、特異値比0.45、相対拡大率0.35〜3で有効性を検査する。最初の基準姿勢が大きく横向きだった場合や、非平面の顔が大きく回転する場合、鼻の推定誤差に限界がある。カメラ校正や真の距離推定を実装した意味ではない。

顔欠測中は腕長の学習を止める。直前の尺度を最大0.5秒だけ使用し、その後は既存の姿勢保持へ移る。この短いキャッシュ中は、距離が変わっても尺度が更新されない限界がある。顔尺度を一度も得ていない場合も実カメラ（image_sizeあり）では学習しない。image_sizeを渡さない旧単体呼出し/テストだけは従来の肩尺度学習を許す。過去記録の手動校正値は旧再処理互換として残っているが、通常起動は常時校正である。

顔の尺度は胴体・掌・指に使う共通XYにも反映する。モデルのZは従来の相対深度のままであり、全身を顔寸法だけから3D復元したものではない。

## 指の観測検査

各指の直近2秒、最大40回の採用した3D骨長から中央値を作る。5回以上集まってから、指節のいずれかが基準の0.45倍未満/2.2倍超なら採用しない。絶対長の既存検査も維持する。除外時は平均窓と方向の連続性を切り、表示基準を保持する（DirectionGate.missing）。次の平均2点で動きを確認して再開する。2秒を超えた古い骨長は更新時に除去される。

これは動体ぼけの画像検出器ではない。骨長を保ったまま点が曲がる誤りは残る。最初の数回が誤っている場合、強い遠近差、実際の曲げに伴うモデルの骨長変動でも保持しすぎる可能性がある。共通の3/1観測ルールの可逆性は維持する。

## 口の形

mouthRoundは口角幅/両眼中心間距離が0.8より小さいほど強くし、差0.22で1とする。真の唇突出の3D測定ではなく、すぼめの代理指標。mouthSmileは上唇中央51と口角48/54の高さ差を、顔のロールを除いた縦方向で測る。下唇/顎の下降を口角上がりに使わない。笑顔という感情の推定ではない。

HAOLAN検査記録で存在を確認したシェイプへ以下を適用する。

| シェイプ | 重み |
|---|---|
| vrc.v_aa | 開閉×(1−すぼめ)×100 |
| vrc.v_oh | 開閉×すぼめ×100 |
| vrc.v_ou | (1−開閉)×すぼめ×70 |
| 口角上げ | 口角上がり×100 |
| 口横広げ | 従来どおり幅−1〜1を−50〜100へ |

視覚からの形状混合であり、発音や5母音の分類器ではない。個人別の口幅中立は未校正で、大きく横を向いたときの誤分類、強調による飽和が残る。旧UDP送信側は新しい2項目を省略して0となる。新項目の有限値検査、表情欠測時の保持を追加した。
