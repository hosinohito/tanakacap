## 実装上の候補と次の順序

現行はRTMWの目尻/目頭からROIを作り、別モデルの虹彩中心とROI中央の差を目線とする。目の輪郭基準と虹彩基準が別モデルなので、切り出しのずれを視線変化と区別できない。本人の正面視線の校正もなく、感度増加は片寄りとノイズも増幅する。

次は同じ眼モデルの輪郭出力を使って虹彩を眼の輪郭に対して測る方式と、現行のROI中央方式を比較するのが具体的な候補。輪郭の点番号・精度・正規化の妥当性を検証してから可逆に導入する。今回は実装していない。顔モデル全体の置換はしない。

次いで目線の独立更新による待ち時間削減を検討する。共有の4観測ルールを無断で外して速さを作らない。別モデルを比較する場合も同じ入力条件で比較する。保存済み数値だけでは新しい画像モデルの再推論はできず、現記録から精度順位は出せない。

当面gaze_gain=2を維持。記録の平均を正面として差し引く自動補正、両眼の片方を根拠なく捨てる変更、さらなる表示増幅は行っていない。生映像は保存していない。
