# 腕の欠測と復帰（2026-09-21）

ユーザー指定により、腕・掌・指の欠測時は最後の姿勢を永久保持せず、机に手を置く姿勢へ移る。頭・表情・胴体の欠測保持と、目線の正面復帰は変更しない。

| 状況 | 動作 |
|---|---|
| 最後の有効観測から0.5秒未満 | 表示姿勢を保持 |
| 0.5秒経過 | その時点の表示姿勢から机上姿勢へ1秒で移行 |
| 再検出 | 待機なしで、その時点の表示姿勢から検出姿勢へ0.5秒で移行 |
| 移行途中に状態が変わる | 現在の表示姿勢を新しい始点にして連続性を保つ |

イージングは `t*t*(3-2*t)`（Smoothstep）。始点は固定し、復帰先は新しい観測に追従する。左右の腕、掌、指は別々に状態管理し、片側や腕の欠測で他の有効部位を停止しない。指の一部だけの欠測は既存の指マスクによる保持を維持する。

部位別通信では受信頻度ではなく、最後の有効な観測の時刻から0.5秒を数える。held/lost通知や同じ観測の再送は待機時間を延長しない。全通信停止でも動作し、推論同期描画も移行中は連続描画する。最初から未検出/OFFの腕も起動後0.5秒で机上姿勢への移行を始める。

机上姿勢はHumanoidの骨長を維持し、上腕を下ろし、前腕をほぼ水平に前へ、掌を下へ向け、指を軽く曲げる。アバター原本は変更しない。実際の机の位置・高さは検出しないため、机への接触を保証するものではない。

顔尺度の1秒制限は撤去。校正済みで腕の関節観測が有効な限り、最後の有効尺度で追従し続ける。顔尺度欠測中・復帰の0.2秒移行中は骨長を学習しない。反対側の肩欠測でも有効な腕は継続する。人物全体の欠測、入力間隔0.3秒超、動画ループでは尺度キャッシュを破棄する。固定尺度中の身体の前後移動による誤差は残る。

検証用batは従来どおり `tanakacap-test.bat`。通常アバターのauto-customと保存済み動画を使用し、実写は表示しない。

実装は `PoseTransition.cs`、`AvatarDriver.DriveArmsWithLoss`、`TrackingParts.LastObserved`、`arm_scale.py`。ビルド時に `PoseTransitionChecks` が待機、Smoothstepの途中値、復帰、途中反転を検査する。実アバターの机上姿勢と左右独立性は `tools/smoke_unity.py --arm-rest-check` で検査する。
