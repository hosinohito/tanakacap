# 指の可変速度追従

2026-09-21、ユーザー指定で通常採用。信頼度の判定とPython側の4フレーム法は変更しない。

Unityの指ボーン反映時、各関節の現在のローカル回転と目標回転の角度差を使う。差3度以下は追従率6/s、15度以上は従来の60/s、その間はSmoothstepで補間する。毎描画の補間係数は `1-exp(-rate*dt)`。左右5指×3関節で独立に計算し、固定速度の補間を置換する。新しい推論や観測待ちは追加しない。

小さな動きも破棄せず目標へ収束する。小さい差では90%追従まで約0.38秒となり、細かな意図的動作にも遅れが出る。低信頼度除外や欠測時の机上姿勢・再検出時の移行時間は既存処理を維持する。実際の手の振動改善はユーザーによる確認が必要。

ビルド時の `FingerFollowChecks` は±2度交互入力の減衰、大きな60度動作への追従、小さな2度動作の収束を30/60/120fpsで検査する。人工振動の二乗平均比は旧方式に対し約0.0142（実人物の改善率ではない）。通常Playerの欠測・復帰検査と既存録画の部位別受信も検査する。

確認はデスクトップの `tanakacap-test.bat` から、録画＋通常アバターの自動キーモードで行う。別PCには `builds/player/` 全体をコピーする。配布版への更新は同一のPlayer一式を `app/` に置く。Python・モデル・アバターの再エクスポートは不要。ZIPは作成しない。
