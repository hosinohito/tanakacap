# 顔距離の静止時変動対策

2026-09-12。ユーザーが静止時の前後ガタつきを申告。FaceScaleは鼻筋/眼端8点のアフィン最大特異値で相対サイズを推定し、距離専用DirectionGateを通す。腕長校正にも使われるFaceScale自体は今回変更しない。

## 今回の変更

tracking-settings.json の face_distance_filter=stable を既定とする。legacyで旧距離処理へ戻る。Unityのframed/seated/translate/OFF、頭/口/目線/腕/指制御は不変。

- 従来の距離比に対する絶対閾値0.008から、対数距離比に対する0.02（約2%）へ変更。近い/遠いで相対的な小変動抑制量が変わらない。
- 3平均/stride1の既存方向継続確認を維持。追加のフレーム待ちは入れない。
- 採用値への時間ベース追従：目標差log0.02以下は時定数0.22秒、0.08以上は0.06秒、間は線形。小動作の遅れを増やす代わりに微振動を抑えるトレードオフで、万能な精度改善とは扱わない。
- 欠測時は最後の内部距離を保持し、復帰でも初期化して新距離へ即座に飛ばない。経過時間を0.1秒までとして再開。初回だけは有効な距離へ初期化する。
- filter_modeと尺度診断を数値記録へ追加。

## 検証

167pytest成功。小さな相対ノイズを近距離/中距離/遠距離で抑制、接近/離反の収束、欠測保持/復帰、旧モードの既存幾何テストを確認。30Hz合成観測で距離比1→0.75のステップ後約0.3秒以内に差0.025未満。カメラから画面までの実遅延ではない。

元の送信値の初期校正を持ち越していないので元記録の距離比や有効数と完全一致しない。静止区間のラベルがなく、表の変化には実動作も含む。静止精度改善や実人物の見た目は未確認。長い周期の誤検出や頭向きに伴う尺度誤差はこのフィルターで除去できるとは限らない。
