# 顔ピッチと口角の向き補正（2026-09-12）

ユーザーは上下を向いたときに頭ピッチが追従せず、口角として誤判定されると報告。頭の表示だけ直しても表情入力は直らないため、ピッチ推定と口角の投影補正を両方追加した。

## 旧経路と記録

旧headPitchは両目中心に対する鼻30の縦距離/眼間距離から、固定0.55と係数70で計算していた。3D回転の推定ではない。口角も画像上の中央唇と左右端の高さ差をそのまま使い、ピッチによる奥行きの投影差を含んでいた。

最新221714は696frame、旧送信pitchは大半（5〜95%）−9.56〜1.40度、口角上限付近（0.95超）は記録で左210/右262。正解の実頭角度や笑顔は未保存で、これだけで全て誤検出とは断定しない。

## 新方式

- 顔検出RTMWと目線モデルは維持。標準顔形状の鼻/眼端9点を既存のRTMW2D点へ当てはめる小さなPnP幾何計算を追加。顎と唇を頭向きの推定に使わない。
- OpenCV既存インストールのSQPnPとLM refinementを使用。GPU推論をCPUモデルへ置換していない。カメラ内部パラメーターは画像寸法からの近似、歪みは未校正。個人専用の顔形状ではなく、精密な角度/距離の保証はしない。
- 再投影誤差、顔サイズ、信頼度、向き、正の深度で不良解を棄却。基準取得後も動的に標準形状を本人の形へ学習しているわけではない。
- 起動後の正面寄り・10観測でpitch範囲6度未満の姿勢を中立とし、差分を感度1.8で±40度へ。頭のヨー/ロールは既存方式を維持し、良好だった顔全体を置換しない。基準は起動姿勢なので、最初から傾いていればその角度が基準になる。
- 口角に必要な点は、各点の標準顔奥行きへ画像の視線を逆投影し、頭基準の正面座標へ戻してから既存contour_controlsへ渡す。左右非対称、への字、横寄せは引き続き独立した観測値。口モーフ、口角ガンマ/倍率、開口時の上げ抑制は変更していない。
- PnP不良時は最後のピッチ入力を保持し、口輪郭更新を無効にする。既存の観測ゲートと描画補間は残る。顔検出全体を停止させない。表情の基準取りも補正後の座標で行う。

設定：head_pose_mode=pnpが新既定。legacyでピッチと口角の座標処理をまとめて旧方式へ戻す。head_pitch_gain=1.8、許容0.5〜3。CLI --head-pose-mode / --head-pitch-gain。診断head_pose（legacy/raw/calibrated pitch、基準、残差、口補正成立）とhead_pose_ms。生映像を保存しない。

## 比較と検証

- 保存記録を同じ開始状態・観測間隔で新旧それぞれ再生した最終比較は、口角0.95超が左217→0、右262→88。初回報告の左210は当時の送信記録との比較であり、再生時の初期校正条件が違う。最終値を採用する。小さくなったことだけで表情精度向上とは断定しない。
- 新ピッチの校正/感度適用後範囲−15.75〜17.05度。696/696で形状適合条件成立、再投影誤差中央値は外眼幅の1.08%。この残差や成立率は正解角度の精度ではない。
- 幾何計算中央値0.52ms/95%0.56ms。記録再生の値で、GPUと競合する実カメラ全体の遅延測定ではない。
- 154 pytest成功。合成3D顔のpitch±30度、yaw/roll/距離/位置変化で口角の値が不変、実際の片側口角の変化が残ること、基準/感度/欠測/退化形状を検査。一般人の顔形状の精度保証にはならない。
- Unityビルド、実Player既存motion回帰成功。上下25度packetから実Head回転への到達誤差0.2度以内を検査。実人物での見え方は未確認。
- 成果物results/head-pose/final-audit.json/jsonl、motion.log、up/down.pngとbones.json。tools/audit_head_pose.pyで再集計可能。

## 2026-09-12 追試

頭ピッチ改善はユーザー確認済み。残る口角連動に対し、口の平均奥行きを固定して各唇点の奥行き差だけを1.5倍にする。鼻/眼端で解く頭姿勢は変更しない。tracking-settings.json の mouth_lip_depth_scale（CLI --mouth-lip-depth-scale）、1.0で前回に戻る。範囲0.5〜2、head_pose_mode=legacyでは未使用。

最新223024の935観測（正面寄り/閉口）の相関は左0.442/右0.488→−0.109/0.012。2倍は逆方向に補正しすぎる傾向。これは固定仮説の記録比較であり、個人形状の真値や正解表情ではない。ライブで表情を学習して引き去る処理はない。合成投影で向き/左右別表情の分離、設定復元、頭pitch不変を検証し162pytest成功。Unity変更なし。実人物品質未確認。
