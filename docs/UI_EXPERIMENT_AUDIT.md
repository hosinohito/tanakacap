接触範囲は頭回避ON時に作用する。頭ピッチ・口の基準形状はそれを参照する頭角度方式だけに作用する。口の基準形状の奥行きは固定テンプレートの調整で、モデルの推定Zを通常方式へ再導入しない。眉感度は表情タブの大げさ度とは別の推定後の倍率。

既存19項目は現行の呼出先を照合して維持。「人物検出」の見出しは「人物切り出し」に統一。頭だけ／顔・頭で使えない3D頭方式は従来どおりPnPへ代替する。FP32はUIの環境指定経由で接続済み。RTMW-LのFP16 Graph非互換によるFP32固定も維持。

## 通常UIへ追加しないもの

- ねじり無制限：比較で複数回転したため不採用。再現用のオフライン診断のみ残す。
- 補正単独比較プリセット：各補正の独立ON/OFFで代替し、重複掲載しない。
- モデル交換、固定頭ROI、画像出力・プロファイラー・人工入力・比較撮影：別モデルや専用試験の入口。
- 信頼度閾値：ユーザー指定どおり変更しない。廃止した「内側の手は前」やデモ専用アバター処理は復活させない。
- 指の可変追従など旧実装の切替が残っていない機能には、新しい旧方式を作らない。
