# TanakaCapの使い方

## 導入

1. 配布ZIPをダウンロードし、好きなフォルダーにすべて展開します。複数のZIPがある場合は、すべて同じ場所へ展開してください。
2. 普段アバターを編集しているUnityプロジェクトを開きます。
3. `プラグイン/TanakaCapExporter.unitypackage` を開いて追加します。
4. アバターの一番上のオブジェクトを選び、メニューの **TanakaCap → Export selected avatar** から保存します。
5. 展開先の `TanakaCap.bat` をダブルクリックします。

NVIDIA RTX搭載のWindows PCが必要です。アバターはご自身で用意してください。書き出し時にエラーが出た場合は、表示された内容を確認してください。

利用条件は配布フォルダー内の「ライセンス」を確認してください。

## 使う

1. 入力を「カメラ」にして、使用するカメラを選びます。
2. 「アバターを選択」で、先ほど保存したファイルを選びます。
3. 「保存して開始」を押します。「停止」で終了できます。

カメラなしで試すときは、入力を「デモモーション」にします。

## 見た目を調整する

- 左ドラッグでアバターのウインドウを移動できます。
- 右ドラッグで上下移動、ホイールで寄り・引き、Ctrl＋ホイールで画角を調整できます。
- **構図** を押すと **保存** と **リセット** が使えます。Escでパネルを閉じます。
- **表情** タブで各部位の動きの大きさを調整します。**規定値** でその項目を戻せます。
- 操作画面の設定は **保存して開始** で反映します。動作中は再起動して反映します。
- **描画・OBS** タブの **背景** で、ウインドウ背景を緑・青・マゼンタに変更できます。初期値の **指定しない** は黒です。Spoutの透過出力には影響しません。

## OBSに映す

OBSにSpout2プラグインを追加し、Spoutソースで **TanakaCap** を選択します。背景が透けた状態で重ねられます。

OBS用プラグイン： https://github.com/Off-World-Live/obs-spout2-plugin/releases
