# 腕の前方補正の単独比較

2026-09-21。ユーザー撮影の `results/comparison-takes/20260921T044937-004325Z` を使用。実写は表示せず、既存FP16経路で１回推論し、同一packet・同一時刻・通常アバターのauto-customで比較する。モデルの再推論差を補正差と混ぜない。

## 頭へのめり込み防止の変更

従来の「顔付近の半径18cm球に入った手首をカメラ側表面へ移す」処理を撤去した。

`HeadClearance.Fit` は読取可能なスキンメッシュのうち、Headボーンの重みが0.5以上の頂点を取得する。目の間隔で探索範囲を制限して長髪・大きな耳・帽子・首の混入を抑え、表情キーのあるメッシュを優先する。各軸の1〜99パーセンタイルから楕円体の中心と半径を決める。十分な頂点がなければ眼間隔に比例する楕円体へ代替する。メッシュ原本は変更しない。

楕円体は頭の回転・位置に追従する。手首目標が内部なら、楕円体の最寄り表面を数値的に求め、表面法線へ2mmだけ余裕を持たせる。横は横、後ろは後ろへ逃がし、前方へ固定しない。頭回避を理由に補間を飛ばす旧処理も撤去した。腕長と関節の到達範囲は既存IKを維持するため、到達不能時の完全な非貫通は保証しない。

これは頭メッシュ自体との衝突判定ではない。手首だけを対象にし、指先・掌の厚み、髪や装飾品との接触、任意の頭形状への完全一致は対象外。今回のアバターはBodyメッシュから半径約(8.0,9.0,7.3)cmを取得した。

## 比較条件

以下は累積ONではなく、毎回基準へ戻して１つだけONにする。保持する「手動校正時の前腕前方優先」はコードを維持するが、今回の自動校正録画では使われない。「投影短縮から奥行きを復元」は全版共通で、その内部の肩より前の手首候補選択も残る。したがって基準版は、生のモデルZをそのまま描画する版ではない。

| 動画 | 基準へ追加する補正 |
|---|---|
| 00-base | なし |
| 01-head | 新しい楕円体の最寄り表面への頭回避 |
| 02-cross-body | 体を横切る手首と肘の前方誘導 |
| 03-wrist-front | Unity側の手首前方制限（上腕前方フラグも同組） |
| 04-legacy-front | 旧モデル経路の内側・重なり前方補正。ただし今回の投影短縮経路では非稼働 |
| 05-outward-elbow | 低く外側に引いた手に対する後方肘候補の選択。前回の一覧外だが、基準から外して別途単独比較 |

有効な腕観測は左757・右800で、すべて投影短縮復元の前方フラグあり、上腕前方フラグなし。旧モデル経路は通らないため、04のために強制的に別アルゴリズムへ切り替えていない。04と基準の実際の肘・手首座標が一致することを確認した。独立プロセスの描画は微差があり、動画画素の完全一致は要求しない。

試験用 `--diagnostic-arm-correction` は `--render-replay` と同時指定でのみ有効。通常起動の補正の採否は変えず、頭回避方式だけを更新する。各動画の `.mp4.json` に頭回避の実変更回数、体横断の条件成立回数、手首目標の前方クランプ回数、後方肘条件成立回数を保存する。回数は描画内のシミュレーションステップであり撮影フレーム数ではない。

## 再実行・成果物

1. `tools/compare_precision.py --take <撮影フォルダー> --output <推論結果> --name recorded --mode graph-fp16` で共通推論を保存する。
2. `tools/diagnostics/compare_arm_corrections.py --source <推論結果> --output <動画フォルダー>` で単独版・一覧・基準との２画面比較を生成する。出力は新しいフォルダーを指定する。

今回の推論：`results/comparisons/arm-corrections`。動画：`results/avatar-videos/arm-corrections-final`。`side-by-side.mp4` は3列×2段、`compare-*.mp4` は左が基準・右が各補正。各版は901描画フレーム、30fps、約30.03秒。元の取得時刻を共通利用し、末尾を１描画フレーム表示するため撮影の公称30秒と僅かに異なる。

最寄り点計算は楕円体表面の密な独立サンプルと比較し、中心・横・後ろ・上・一般位置を含めビルド時に検査。320 Python testsと通常Playerの欠測・復帰検査に成功。汎用 `--motion-check` は今回の頭回避検査へ到達する前に、旧保持仕様を期待する `CheckSeatedPose` の「Held elbow did not follow chest with local pose intact」で停止した。汎用検査全体の合格とは扱わず、旧保持検査の改訂は別課題とする。実カメラ試験・実写表示なし。動画の見た目の評価はユーザーが行う。

別PCへの本体更新は `builds/player/` 全体（配布版ならPlayer一式を `app/`）。比較動画だけ見る場合は動画フォルダーのMP4のみでよい。Python推論・モデル・アバターの再書出しは今回不要。ZIP・公開なし。

## 今回の観測結果

全12本の生成・全編デコード成功。実際の肘・手首の座標を比較すると、体横断補正の最大成分差は約16.0cm、手首前方制限は約3.7mm。他の３版は基準と一致した。これは軸ごとの最大差で、正解からの誤差ではない。体横断条件833回、手首目標クランプ15回。新しい頭回避・後方肘条件は0回で、この録画ではそれらの接触時品質を評価できない。旧経路補正も投影短縮経路では非稼働。

初回 results/avatar-videos/arm-corrections は描画画素の完全一致を要求した検査で停止した旧成果物。実骨座標による隔離検査へ改めて再ビルド・再描画した arm-corrections-final を最終版とする。
